# Game UI Assets — Garry's Mod UI/UX Specialist

Специализированный навык для разработки интерфейсов Garry's Mod: поиск готовых качественных ассетов, проверка лицензий, конвертация в совместимые форматы и создание оптимизированного GLua-кода.

## Автоматическое применение
Применяется при любых задачах, связанных с:
- Созданием или редизайном HUD, шкал, индикаторов здоровья/жажды/брони.
- Разработкой меню (диалоги NPC, профессии, настройки, инвентарь, торговля).
- Подбором или внедрением иконок, рамок, текстур и фонов.
- Работой с материалами `Material()` и библиотеками `vgui`, `surface`, `draw`.

---

## Обязательный алгоритм работы (9 шагов)

### Шаг 1: Декомпозиция графических потребностей
Определить точный перечень визуальных элементов для задачи:
- Тип элемента (иконка статуса, фон карточки, рамка слота, текстура шума, градиент).
- Требуемый размер отображения (16x16, 32x32, 64x64, 128x128).
- Наличие прозрачности (RGBA) или плотный фон.

### Шаг 2: Поиск готовых ассетов перед ручной отрисовкой
Не рисовать сложную графику примитивами вручную, если есть готовые решения.
1. Проверить встроенные ресурсы Garry's Mod:
   - `materials/icon16/*.png` (более 1000 иконок Silkicons — не требуют загрузки клиентом).
   - `materials/gui/gradient*` (градиенты движка).
2. При необходимости внешних ассетов обратиться к проверенным открытым библиотекам.

### Шаг 3: Источники с разрешенным использованием
Искать исключительно на проверенных ресурсах с прозрачной лицензией:
- **FreeGameUI** ([https://freegameui.net/](https://freegameui.net/)) — CC0 1.0 (Public Domain), кнопки, рамки, индикаторы.
- **Kenney UI** ([https://kenney.nl/assets/series:UI](https://kenney.nl/assets/series:UI)) — CC0 1.0 (Public Domain), готовые спрайты интерфейсов.
- **OpenGameArt** ([https://opengameart.org/](https://opengameart.org/)) — CC0, CC-BY, предметы инвентаря.
- **Game-Icons.net** ([https://game-icons.net/](https://game-icons.net/)) — CC-BY 3.0, монохромные векторные значки.

### Шаг 4: Проверка лицензии и технических параметров
Для каждого найденного ресурса проверить:
- **Лицензия:** Допустимо ли коммерческое/некоммерческое использование без строгих ограничений GPL.
- **Формат:** Является ли файл растровым (PNG) или векторным (SVG).
- **Разрешение:** Оптимально кратное степеням двойки (32, 64, 128, 256, 512).

### Шаг 5: Безопасное скачивание и фильтрация
1. Скачивать выбранные файлы только в отдельную временную папку проекта (например, `temp_assets/`).
2. Не скачивать исполняемые файлы (`.exe`, `.bat`, `.dll`) или сторонние пакеты npm/pip без явного указания пользователя.
3. Проверить целостность и скопировать только нужные файлы в папку `garrysmod/materials/<addon>/...`.

### Шаг 6: Фиксация авторства и метаданных
Для каждого импортированного файла внести запись в `docs/ui-assets.md` (или соответствующий лог):
- URL источника
- Тип лицензии (CC0, CC-BY 3.0 и т.д.)
- Оригинальное имя файла
- Итоговый путь в проекте

### Шаг 7: Совместимость с движком Source (Запрет прямого SVG)
- **Source НЕ поддерживает SVG напрямую.**
- Если ассет получен в SVG, его необходимо преобразовать в PNG (32-bit RGBA) с прозрачным фоном перед помещением в `materials/`.
- Проверить, что PNG не поврежден и открывается графическими библиотеками.

### Шаг 8: Чистая интеграция в GLua
- Кешировать материалы **строго на уровне файла** (`file scope`), никогда не вызывая `Material(...)` в `Paint` или `HUDPaint`:
  ```lua
  local MAT_ICON = Material("oasis/icons/my_icon.png", "smooth noclamp")
  ```
- Использовать `surface.SetMaterial(MAT_ICON)` и `surface.DrawTexturedRect(...)`.
- Масштабировать координаты и размеры пропорционально `ScrW()` / `ScrH()`.

### Шаг 9: Обработка ошибок и альтернативы
Если внешний сайт недоступен, ссылка устарела или скачивание невозможно:
- Немедленно уведомить пользователя.
- Предложить альтернативный готовый ассет из встроенных `icon16` или геометрическую стилизацию с градиентами движка.

## Критерии проверки (Checklist)

- [ ] Проверено наличие аналога среди встроенных `icon16` или локальных файлов.
- [ ] Источник проверен, лицензия CC0 или совместимая CC-BY.
- [ ] Формат проверен: в `materials/` попадают только PNG/VTF, никаких "сырых" SVG.
- [ ] В коде GLua материал кешируется один раз при загрузке файла.
- [ ] Источник и лицензия задокументированы в `docs/ui-assets.md`.
- [ ] Координаты отрисовки масштабируются от разрешения экрана пользователя.
