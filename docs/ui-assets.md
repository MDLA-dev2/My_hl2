# Руководство по графическим ассетам UI для Garry's Mod

> Инструкция по поиску, проверке, конвертации и интеграции иконок, текстур и рамок для интерфейсов Garry's Mod.

---

## 1. Проверенные источники готовых ассетов

| Источник | URL | Лицензия | Форматы | Подходит для |
| :--- | :--- | :--- | :--- | :--- |
| **FreeGameUI** | [https://freegameui.net/](https://freegameui.net/) | **CC0 1.0 (Public Domain)** | SVG (нужна конвертация в PNG) | Кнопки, панели, шкалы, иконки, текстуры шума |
| **Kenney UI** | [https://kenney.nl/assets/series:UI](https://kenney.nl/assets/series:UI) | **CC0 1.0 (Public Domain)** | PNG (с прозрачностью) | Готовые спрайты кнопок, слотов, индикаторов |
| **OpenGameArt** | [https://opengameart.org/](https://opengameart.org/) | CC0, CC-BY 3.0/4.0 | PNG, PSD, TGA | Иконки инвентаря, предметы, оружие, текстуры |
| **Game-Icons.net** | [https://game-icons.net/](https://game-icons.net/) | **CC-BY 3.0** (требует указания авторства) | PNG (до 512x512), SVG | Стилизованные векторные иконки перков, навыков, предметов |
| **GMod Built-in** | Локально в клиенте | Проприетарная Valve/FamFamFam | PNG (16x16), VMT/VTF | Silkicons (`icon16/*.png`), градиенты (`gui/gradient*`) |

## 2. Технические ограничения движка Source (Garry's Mod)

> [!IMPORTANT]
> **Движок Source НЕ поддерживает формат SVG напрямую.**
> Попытка вызвать `Material("my_icon.svg")` приведет к ошибке или отображению розово-черных текстур (Missing Texture).

### Поддерживаемые форматы:
1. **PNG (32-bit RGBA):**
   - Самый простой и удобный формат для пользовательского интерфейса в GLua.
   - Поддерживает альфа-прозрачность.
   - Рекомендуется сохранять в степенях двойки (`32x32`, `64x64`, `128x128`, `256x256`, `512x512`) для идеального сглаживания без артефактов mipmap.
2. **VTF / VMT (Valve Texture Format / Valve Material Type):**
   - Родной формат движка. Быстрее загружается в память видеокарты при массовом использовании.
   - Требует компиляции через `vtex.exe` или конвертации в VTFEdit.
3. **JPG:**
   - Подходит только для фоновых непрозрачных изображений (экраны загрузки, постеры).

## 3. Пайплайн подготовки ассетов (Конвертация SVG в PNG)

Если вы берете ассеты с **FreeGameUI** или **Game-Icons** в формате SVG:

1. Скачайте исходный файл во временную директорию (например, `temp_assets/`).
2. Преобразуйте SVG в PNG с прозрачным фоном и разрешением 64x64 или 128x128 пикселей.
3. Переместите готовый PNG в структуру материалов гейммода:
   ```
   garrysmod/materials/oasis/
   ├── icons/           # Иконки предметов, ролей, статусов
   ├── ui/              # Рамки, подложки, фоны карточек
   └── decals/          # Граффити, символы фракций
   ```
4. Зафиксируйте в документации:
   - Исходный URL
   - Лицензию
   - Имя оригинального файла

## 4. Использование в GLua коде

```lua
-- 1. Кеширование материала в начале файла с флагами сглаживания:
local MAT_WATER_FLASK = Material("oasis/icons/water_flask.png", "smooth noclamp")

-- 2. Отрисовка в хуке Paint или HUDPaint:
hook.Add("HUDPaint", "oasis/hud/draw_icons", function()
	surface.SetDrawColor(255, 255, 255, 255)
	surface.SetMaterial(MAT_WATER_FLASK)
	surface.DrawTexturedRect(40, 40, 32, 32)
end)
```
