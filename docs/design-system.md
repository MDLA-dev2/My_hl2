## 2. Типографика и масштабирование

Шрифты регистрируются с базовым масштабом `scale = math.Clamp(ScrH() / 1080, 0.7, 1.5)`:

1. **`OasisRP.FontSmall`** (Размер: ~14px):
   - Описания предметов, второстепенные подсказки, подзаголовки карточек.
2. **`OasisRP.FontMedium`** (Размер: ~18px):
   - Обычный текст диалогов, названия полей, кнопки стандартного размера.
3. **`OasisRP.FontLarge`** (Размер: ~24px):
   - Заголовки карточек профессий, имя персонажа в HUD.
4. **`OasisRP.FontHeader`** (Размер: ~32px):
   - Главные заголовки окон, экраны побед/кризисов.

## 3. Сетка и отступы

* Базовый модуль сетки: **8px** (scaled).
* Отступы от краев экрана для HUD: `math.Round(ScrW() * 0.02)`.
* Внутренние отступы панелей (`DockMargin` / `DockPadding`):
  - Малый отступ: 4px–6px
  - Стандартный отступ: 8px–12px
  - Внешний отступ карточки: 16px–20px
* Радиус скругления углов (`draw.RoundedBox`):
  - Окна и карточки: `4px`–`6px` (строгая геометрия)
  - Прогресс-бары и индикаторы: `3px`

## 4. Компоненты интерфейса

### Кнопки действий (`DButton`):
* **Обычное состояние:** Заливка `Theme.AccentAmber`, текст `Theme.TextDark`.
* **Наведение (Hover):** Осветление `Color(245, 180, 80)`.
* **Нажатие (Click):** Звуковой отклик `ui/buttonclickrelease.wav`.
* **Отключенное состояние (Disabled):** Заливка `Theme.PanelLight`, текст `Theme.TextMuted`.

### Прогресс-бары:
* Двухслойная отрисовка: темная подложка `Theme.PanelLight` + закрашенный прогресс.
* Плавная интерполяция значений через `Lerp`:
  ```lua
  smoothVal = Lerp(FrameTime() * 8, smoothVal, targetVal)
  ```

### Скроллбары (`DScrollPanel:GetVBar`):
* Толщина: 4px–6px.
* Скрывать стандартные стрелки `btnUp` и `btnDown` (`Paint = function() end`).
* Бегунок `btnGrip`: закругленный прямоугольник с цветом `Theme.Border`.
